## Key data flows

```
Browser request
  └─ Next.js App Router
       ├─ layout.tsx          ← loads fonts, Nav, Footer, GSAP
       │    └─ getContentMany(["global.nav","global.footer"])  ← Supabase
       └─ page.tsx (route)    ← assembles section components
            └─ Server Actions / Supabase queries
                 └─ src/lib/actions/*.ts
                      └─ src/lib/supabase/server.ts
```

```
CMS edit flow
  /admin/content/:key
    └─ ContentForm.tsx
         ├─ reads schema from src/lib/cms/registry.ts
         └─ calls upsertContent() server action
              └─ writes to Supabase "site_content" table
                   └─ getContent() picks it up on next request
```
